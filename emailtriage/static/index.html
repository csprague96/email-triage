Drafts are saved in your Outlook Drafts folder as replies to the original email. Open one, read it, edit, send. Nothing is ever sent automatically.

Each tag is a yes/no question Jev answers for every email. Write the description as the thing that makes the tag apply. Changes take effect for newly triaged mail; use "Re-assess" on an email to apply them retroactively.

These descriptions are exactly what Jev is told each level means. Tune them to how you think about your inbox. Corrections you make on individual emails are also fed back to Jev as examples.
